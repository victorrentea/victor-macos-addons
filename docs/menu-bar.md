# Menu Bar & Menu (MenuBarManager)

What stays a menu row and why; rows removed in favour of the ⌘⌃ cheat-sheet (see `keyboard-overlays.md`).

- **☠️ Kill port** — submenu with recent ports + custom port dialog

**Banner chip layout (2026-06):** The bottom-left notification pill (`BottomLeftBanner`) renders the hover-hint chip ("Hover to undo/snooze/continue/Send") **pinned to the pill's bottom-left corner** (fixed — no longer riding/moving), with the **orange countdown bar filling the region to the right of the chip** (from the chip's right edge to the pill's right edge) left→right. Countdown banners are floored at **30% of the screen width** (`countdownMinWidthFraction`) so the fixed chip and the bar to its right always fit; plain (non-countdown) banners still hug their text. Reusable across every banner caller.

> **The ⭐️ Effects submenu and the 🔥 Whip Agent row left in 2026-09**, with the
> effects themselves, and are in the `victor-effects` menu (🎆) now — same rows,
> same order, same ⌃W key equivalent. `MenuBarManager` keeps no callback, no
> action and no row for either of them any more. The *rationale*
> for keeping a menu row next to a global hotkey travelled with them: a row is
> the fallback on a Mac that has not granted Accessibility, and the place the
> shortcut is taught. See `victor-effects/docs/whip.md`.

**Menu (2026-08-14) — the menu is not a second cheat-sheet.** Holding ⌘⌃ draws every one of this app's ⌘⌃ shortcuts on the secondary screen at once (`KeymapOverlay`), which is faster than opening a menu and walking a submenu — so rows whose only content was "this key exists" were removed: **📕 Catalog** (⌘⌃K), **📧 Gmail** (⌘⌃G), **📅 Calendar** (⌘⌃L), **Tile Terminals** (⌘⌃A), **Terminal in workspace** (⌘⌃T), **🎅 workspace (plain)** (F8) and the two greyed-out reminders (⌘⌃V *Paste Emotions*, ⌘⌃S *Selection to Notes*). Every one of those keys is still bound in `EventTapManager` — only the rows are gone, and `MenuBarManager.onOpenCatalog` / `onOpenGmail` / `onOpenCalendar` survive as the tap's landing points. **🔁 Restart** went too (reopening the app relaunches it). **`🎅 workspace` was broken**, not redundant: it opened claude in `~/workspace/ai`, a folder that became `skills-private` and no longer exists. What the Extra submenu keeps is what no key replaces: the **toggles** — Emoji Overlay, 🔄 Reverse Mouse Wheel, 🔋 Claude prevents sleep, 🏠 Home Wi-Fi, 📶 Victor Phone Hotspot Fallback and Dark Mode — i.e. state that appears nowhere else on screen.

**📸 Screenshot (hold to crop)** is one row teaching both halves of ⌃P.

## The 2026-09-14 pass

Five rows changed place or left, all for the same reason: the top level had grown rows that were *arguments of a feature*, and the Extra submenu was hiding rows that were *features*.

- **✉️ Draft TO DO mail with clipboard — deleted**, and `GmailCompose.swift` (plus its tests) with it. It had already lost ⌘⌃M to 📤 *Mail clipboard to myself* on 2026-09-08 — the two were the same gesture and the sent one won — and what was left was the same note, unfinished, waiting in a Chrome window for a second decision.
- **📝 Paste Clipboard to Notes left 👩🏻‍💻 Extra for the top level**, directly under 📤, and brought a sibling: **🤖 Paste Clipboard as Prompt**, the same clipboard filed with the 🤖 marker so it lands on the participants' *Prompts* tab. The four clipboard rows now read as one block answering *what is on the clipboard and where does it go* — the wall, Victor's inbox, the notes, the Prompts tab. The 🤖 row carries **no key equivalent** on purpose: ⌘⌃P prefers the *selection*, and a menu click has none (the menu holds the focus), so `SessionNotesAppender.appendClipboardAsPrompt()` is deliberately the clipboard-only half rather than a row whose title promises the key's behaviour.
- **📝/🤖 renamed to Send… (2026-09-15).** Both filed the clipboard somewhere the moment they were clicked — "Paste" was left over from when they were considered a keyboard-shortcut label, not a menu verb — so they read **📝 Send Clipboard to Notes** / **🤖 Send Clipboard as Prompt** now, and a third row joined them: **📥 Paste image to Downloads**, right after the pair, which is the one case none of the clipboard→notes/prompt rows cover — just the file, on disk, no picker. "Paste" stays correct for that one: it is the only row of the three that actually *pastes* (writes a file) rather than filing the clipboard into a running document.
- **🤖 now advertises ⌘⌃P (2026-09-16).** The row that used to carry *no* key equivalent on purpose carries one as a **label**: the menu is where a shortcut is learned, and the one row whose entire subject is the 🤖 gesture was the one row not naming the key that performs it. Nothing about the behaviour moved — the event tap swallows ⌘⌃P before AppKit could match a menu equivalent (same as ⌘⌃M on 📤 above), so the row still cannot fire twice, and it is still the clipboard-only half: ⌘⌃P prefers the *selection* when there is one and a menu click has none (the menu holds the focus). That difference lives in the row's tooltip instead of in an absent shortcut nobody could read.
- **📋 Clipboard History… joined the block (2026-09-16).** The row under the four clipboard rows, and the only one that answers *what was on the clipboard before*: the ⌘⇧V bezel (`docs/clipboard-history.md`), which is Flycut's gesture with images. Its key equivalent is a label like the two above it — the tap swallows ⌘⇧V — and **a click opens it in clipboard-only mode**: the hotkey ends by releasing ⌘ and pasting, a menu click has no held key to release and no claim on which window should receive a synthetic ⌘V, so the pick lands on the clipboard and Victor pastes it where he means to.
- **🎙️ Distil the last 40 s of speech — a new row (2026-09-17)**, directly above 🔬 *Fact-check last 10 min*, because the pair asks the same question: act on what was just *said* in the room. It exists because the transcript picker **lost ⌘⌃V** that day to 📝 *Send Clipboard to Notes*, and a hotkey was its only entry point — the append is reached for a dozen times a day in any app, where the picker only means anything while Whisper is running. The row carries **no key equivalent**, because the feature genuinely has none now; the one thing a menu row must never do is promise a key that does nothing. 📝 *Send Clipboard to Notes* advertises **⌘⌃V** in its place (it was ⌃⌥V), still only as a label — the tap swallows it.
- **🟡 Cursor Glow — deleted**, row, `CursorGlow.swift` and stored setting. It faked a pointer glow macOS has no API for by chasing `NSEvent.mouseLocation` with a click-through panel every 30 ms; it stayed an experiment and never became something a workshop needed.
- **The 🎅 per-repo claude launchers — deleted.** `🎅 workspace` had already gone when `~/workspace/ai` became `skills-private`; `🎅 training-assistant` and `🎅 macos-addons` followed, because a row per repo is a list that only grows and F8 / ⌘⌃C opens claude where the work is.
- **Dark Mode is a checkbox now.** It toggles a state, and a toggle that does not tick reads as an action — which is what makes you click it just to find out which way it goes. The tick is repainted on every menu open from `DarkModeToggle.isDarkNow()`, a **live** read of `NSApp.effectiveAppearance`, not from the enum's `_cachedIsDark`: that cache only knows about flips this process made, and System Settings flips the same switch. **⚫ prefix (2026-09-15)**: every other row in the submenu opens with an emoji — this was the one bare title, leaving the native checkmark to carry the whole "this is a toggle" signal alone.
- **Both hotspot rows name the phone**: 📶 *Victor Phone Hotspot Fallback* and 📱 *Start Victor Phone Hotspot Now*. "Hotspot" alone reads as the Mac's own sharing; what these do is reach the Galaxy running `victor-phone-addons` over Bluetooth and make **it** hand out the network — and when the room's Wi-Fi has just died, which device is about to be asked for internet is the whole question.
- **🐕 Tail moved into the 💬 Transcribing submenu**, alone above its own separator. Its title is a readout *of* the transcription ("🐕 Tail 2 minutes ago" answers how fresh the transcript is), so it belongs under the row that says whether transcription is running at all. Everything below that line is a *setting* — which mic is heard, whether it also goes to disk — and the separator is what stops the readout being read as one. **🔬 Fact-check last 10 min kept the top level**: it is not a readout, it is something you fire mid-sentence and want in one click.

**⏱️ Resumed — the row that colours (2026-08-14).** "⏱️ Resumed 1h 51m ago" turns **yellow past 1h15m** and **red past 1h45m** (`RHTimerMonitor.urgency`, pure + unit-tested; thresholds are Victor's teaching rhythm — a section runs about an hour and a quarter, and past an hour and three quarters the room is gone). The row is read at a glance mid-sentence, so the colour has to carry it: by the time you have *read* "1h 52m" you have spent the attention the glance was meant to save. It is drawn through `attributedTitle` because the item is **disabled** — a readout, nothing to click — and AppKit dims a disabled item's plain title, which is the opposite of what a warning wants; an explicit foreground colour survives that dimming. The yellow is appearance-resolved like the menu-bar apple glyph (`systemYellow` reads on a dark menu and vanishes on a light one, so light mode gets a dark amber). The ⏱️ moved into `RHTimerMonitor.formatElapsed` itself, so the row no longer changes shape the moment it starts saying something.

## 📤 Mail clipboard to myself

Sits **directly under 🔳 Display clipboard link**, because the two rows answer the same question — *what is on the clipboard* — and differ only in where it goes: one puts it on the wall for the room, this one mails it to Victor as a `Reminder` (⌘⌃P, `ReminderMail`; the mechanism is in [hotkeys-launchers.md](hotkeys-launchers.md)).

It breaks *the menu is not a second cheat-sheet* knowingly, and not on the 🔴 raw-audio row's terms — there is no invisible state here to reveal. The justification is the other one: **this key SENDS**, into a real inbox, with nothing to confirm and nothing to undo. Every removed row was a shortcut for something reversible; a menu row is the deliberate, aimed form of an irreversible gesture — you read the title before you click it, which is not true of a key you hit mid-sentence.

The row carries `⌘⌃P` as a real `keyEquivalent`, not as text in the title, and it **cannot fire the send twice**: the event tap returns `nil` for ⌘⌃P, so the keystroke never reaches AppKit and the menu equivalent never matches. That makes the equivalent a fallback as well as a label — with no Accessibility grant the tap is not running, and the menu is then the only way to fire it at all.

The click runs `sendClipboardReminder()` off the main thread, exactly as ⌘⌃P and `GET /test/reminder` do: the pasteboard read and any JPEG re-encode happen inline, and only the receipt banner hops back.

## 🔴 Record raw audio

A checkbox row at the **bottom of the 💬 Transcribing submenu**, under a separator that divides it from the mic-source rows above (which since 2026-09-14 have 🐕 Tail and a separator of their own above them): those choose *which* mic is heard, this one decides whether that mic is also written to disk. It used to be a top-level row and breaks the "the menu is not a second cheat-sheet" rule on purpose, and the justification is narrow: while it is on, the microphone is being written to disk, and **there is no other place that fact appears**. Every other row here either triggers something or repeats a shortcut; this one is the only readout of an invisible, privacy-relevant, disk-filling state — so it also carries how much is recorded (`🔴 Recording raw audio — 2.4 h`), which is the next question anyone asks. Off, it reads plainly as `Record raw audio`, with no 🔴 and no checkmark, so the on-state cannot be mistaken at a glance. Moving it inside a submenu would have destroyed exactly the visibility that justifies it, so two things compensate: while capture is on the **🔴 prefixes the parent `Transcribing` title itself** (in every state — the mic keeps being written to disk whatever transcription is doing), and the parent row now **keeps its submenu and stays enabled even when transcription is off or battery-paused**, since a disabled parent would make a running capture impossible to stop at the exact moment you most want it gone. The row is also painted from `isRecordingRaw`/`recordedRawHours` held on `MenuBarManager` rather than straight onto the item, because `AppDelegate` reports the state **before** the menu is built — writing it to a nil item silently lost a capture that was already armed at launch. Details and the file format are in [transcription.md](transcription.md).

## 🔄 Reverse Mouse Wheel

A checkbox in the **👩🏻‍💻 Extra** submenu and the **only row in the whole menu whose default is on**. It breaks *the menu is not a second cheat-sheet* on the 🔴 raw-audio row's terms rather than despite them: there is no key to teach — nothing is bound — and no other place in the app where the state appears. When a scroll goes the wrong way the first question is "is this app doing that?", and this row is the only thing that can answer it.

The default is the point, and it is the one thing that could have shipped wrong silently. The row replaces **Scroll Reverser**, a utility that was *already running* when it was uninstalled (2026-09-07), so a first launch with nothing stored has to reproduce the machine as it was — and `UserDefaults.bool(forKey:)` answers **false** for a key nobody has written, which is exactly how a replacement like this ends up installed in the off position with no error anywhere. `ScrollReversalSettings.isEnabled` is therefore `object(forKey:) as? Bool ?? true`, and there is a test that removes the key and asserts on it.

**Nothing is notified when it is clicked**, unlike every other toggle here. The event tap reads `ScrollReversalSettings` itself, on the scroll event it is already holding, so there is no cached mirror and no window in which the tick and the wheel disagree — the failure mode a "push the new value to the component" toggle has by construction. It costs a `UserDefaults` lookup per scroll event, measured at 630 ns (200k reads, `-O`) against a tap whose watchdog is measured in seconds. The mechanism, the trackpad exclusion and why the reversal sits *ahead* of the Cmd+scroll font zoom are in [hotkeys-launchers.md](hotkeys-launchers.md).
