# victor-macos-addons

macOS menu-bar utilities (💬) for live training workshops: Whisper transcription,
hotkeys and launchers, the break timer, screenshots, the tablet link and the
participant join link. See [CLAUDE.md](CLAUDE.md) and [docs/](docs/).

The desktop **effects**, the **soundboard** and the 🔥 **whip** live in a
separate app since 2026-09:
**[victor-effects](https://github.com/victorrentea/victor-effects)** (🎆, port
55124). This app keeps port 55123 and proxies the effect and sound routes to it,
so nothing that already pointed at 55123 had to change.
